# 🛒 E-Commerce Application

An advanced Full-Stack E-Commerce Application built using the MERN Stack (MongoDB, Express.js, React.js, Node.js) with secure admin panel, product management, user authentication, image upload (Cloudinary), and more.

## 🚀 Features

### 👤 User
- Register / Login with JWT Authentication
- View products with filtering & sorting
- Add to cart and wishlist
- Place orders securely
- Leave product reviews & ratings

### 🛠️ Admin
- Admin dashboard with analytics
- Create, Update, Delete products
- Upload product images using Cloudinary
- Manage users and orders
- Review moderation

## 🧰 Tech Stack

### Frontend
- React.js + Redux Toolkit
- Tailwind CSS
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js
- MongoDB + Mongoose
- Cloudinary (image upload)
- Multer (file handling)
- JWT & bcrypt.js (Authentication)
- dotenv

## 📁 Folder Structure

## ⚙️ Getting Started

### Prerequisites

- Node.js
- MongoDB
- Cloudinary Account (for image uploads)

### Clone the repository

```bash
git clone https://github.com/Rahulkrcse124/E_Commerce-Application.git
cd E_Commerce-Application
```

### Backend Setup

```bash
cd server
npm install
# Create .env file with:
# MONGO_URI=your_mongodb_connection_string
# JWT_SECRET=your_jwt_secret
# CLOUDINARY_NAME=your_cloudinary_name
# CLOUDINARY_API_KEY=your_cloudinary_api_key
# CLOUDINARY_API_SECRET=your_cloudinary_api_secret
npm start
```

### Frontend Setup

```bash
cd client
npm install
# Vite is used as build tool
npm run dev
```

### ⚡ Run the Application

- Frontend: `http://localhost:5173`
- Backend API: `http://localhost:4000`
